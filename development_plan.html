AI Semiconductor 6AM 개발 플랜

한국장 개장 전 삼성전자, SK하이닉스, 반도체 소부장 ETF 관점에서 매크로·뉴스·AI 투자 사이클을 종합해 Telegram으로 보내는 자동화 개발 계획입니다.

대상: 한국 반도체 투자 판단 시간: 매일 06:00 KST LLM: OpenRouter free 우선 Fallback: 규칙 기반, 로컬 Qwen은 선택

개발 방향

1차 목표는 GitHub Actions에서 qwen/qwen3-32b:free를 호출해 Mac이 꺼져 있어도 매일 06:00에 리포트를 받는 것입니다.

로컬 Qwen/Ollama는 품질 비교와 주간 심층 분석용으로 남기되, 배터리 잠자기 상태가 많은 생활 패턴을 고려해 운영 경로에서는 제외합니다.

시스템 구성

Primary

GitHub Actions + OpenRouter free

  • Mac이 꺼져 있어도 GitHub 서버에서 실행
  • qwen/qwen3-32b:free로 최종 10항목 리포트 생성
  • UTC 일-목 21:00, 한국시간 월-금 06:00 실행
  • Telegram Bot API로 채널 발송
Optional

로컬 Qwen/Ollama

  • Mac이 켜져 있을 때 수동 비교
  • qwen3:32b 또는 qwen3:14b 테스트
  • 주간 심층 리포트에 활용
  • 운영 자동화에는 사용하지 않음

개발 단계

Step 1

OpenRouter free 연결

GitHub Secrets에 OPENROUTER_API_KEY를 등록하고 qwen/qwen3-32b:free 모델로 수동 실행합니다.

Step 2

품질 평가

3일치 리포트를 저장해 판단 강도, 한국어 품질, 뉴스 반영도, 숫자 정확성을 확인합니다.

Step 3

무료 모델 실패 기준

free 모델이 rate limit, timeout, 품질 저하를 반복하면 다른 :free 모델 또는 저가 Qwen 모델로 교체합니다.

Step 4

자동 실행

GitHub Actions의 schedule을 사용합니다. 현재 설정은 한국시간 월-금 06:00입니다.

Step 5

백업 경로 유지

OpenRouter가 실패하면 규칙 기반 fallback이 Telegram 메시지를 보내도록 유지합니다.
